# Workflow rules

- Never commit or push directly to `main`.
- Make every change on a new branch and open a pull request.
- Branch names that implement a feature must start with feature/, fixes with fix/.
- Commit messages and PR descriptions must describe what changed. Do not include who made the changes (no co-author or "generated with" lines).
- PRs are reviewed and merged manually by the maintainer. Do not merge them.
- After a pull request has been merged and the associated branch deleted, please clean up the branch locally.
